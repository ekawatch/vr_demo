# walking_xr — เดินในพื้นที่ภูเขาด้วย WebXR (SCMA292 lesson 12)

แอป mobile WebXR ให้ผู้ใช้ **เดินในพื้นที่เปิด** ที่-render เป็นภูมิประเทศภูเขา
(เนิน + กำแพงเขาหินล้อมรอบ) — พื้นที่ **กว้างด้านละ 3 เท่า** (เดินได้ ±64.5 m,
mesh ±102 m, กำแพงเขาสูง ~50 m) มีพืช **5 ชนิดจัดเป็นโซน** (แต่ละบริเวณมีชนิดเดียวกัน
ขึ้นชิดกัน): ต้นสน, ต้นทรงกลม, พุ่มเตี้ย, **กล้วย** (ลำต้นเขียว+ใบยาวห้อย) และ
**ไม้ล้มลุก** (ใบงอกจากพื้น เดินผ่านได้) พร้อม **ผีเสื้อบินวนรอบผู้เล่น** (กลางวัน)
และ **นกบินกระพือปีกเป็นวงเหนือพื้นที่**

## วิธีควบคุม (ตามที่โจทย์กำหนด)

- **มองต่ำประมาณ 20° จากขอบฟ้า** → ตัวキャラจะเริ่ม **เดิน smoothly ต่อเนื่อง**
  ไปตามทิศที่มอง (มองตรง = เดินตรง, มองซ้าย/ขวา = เลี้ยวซ้าย/ขวา)
  โดยทิศ = องค์ประกอบแนวนอนของ direction ที่หันศีรษะ
- มองลึกขึ้น → เร็วขึ้น (ถึง ~48° = ความเร็วสูงสุด **2.3 m/s = 2× เวอร์ชันแรก**;
  exponential smoothing + จำกัด acceleration 5 m/s² กันกระชาก)
- ก้มเกิน 70° (มองแทบตรงลงพื้น) → ทิศไม่มีความหมาย → ใช้ทิศล่าสุด (LAST LOOK)
- **สิ่งกีดขวาง:** ลำต้นพืชทุกชนิด, ความชัน > 18°, และขอบเขต (เดินได้ -64.5..64.5 m)
  — **เว้นไม้ล้มลุก (herb): เดินผ่านได้เลย** ไม่กันทางเดิน
- **ไม่มีป้าย/ข้อความในฉาก 3D** (ตามที่ผู้ใช้ขอ) — โหมดจอธรรมดามี panel 2D
  แสดงสถานะและข้อความ blocked
- **วงสถานะการเดิน:** เมื่อก้มถึง ~20° วงกลมเต็มวงสีโอลีวจางบนพื้นที่จุดที่มอง;
  เงยขึ้นกว่านั้นวงหายไปทั้งวง
- **FOV กว้าง 2×** ในโหมดจอธรรมดา (~111° แนวกว้าง) ให้เห็นฉากกว้างเหมือนยืนจริง
  (ใน headset ความกว้างสายตาเป็นของอุปกรณ์ ปรับจากโค้ดไม่ได้)
- **ตกแต่งพื้น:** ก้อนหินหลายขนาดฝังครึ่ง + กระจุกหญ้า + ไม้ล้มลุก กระจายทั่วสนาม
- **กลางวัน–กลางคืน:** ดวงอาทิตย์/ดวงจันทร์เป็น light source จริง (เงาตกตามทิศ),
  ท้องฟ้าเปลี่ยนสีตามเวลา, ดาวหมุนช้า ๆ — **ค่าเริ่มต้นรอบวัน 10 นาที = กลางวัน 5 นาที
  กลางคืน 5 นาที** (นั่งรอจะเห็นมุมแดด/มุมจันทร์เคลื่อนต่อเนื่อง); นาฬิกาของโลกเดินด้วย
  **เวลาจริง** (dt แยกจาก dt ของฟิสิกส์) จึงได้ 5/5 นาทีเท่าเดิมแม้เฟรมเรตต่ำ;
  ปรับได้ `?tod=ชม.` และ `?dayspeed=ตัวคูณเวลา` (144 = ค่าเริ่มต้น, 0 = หยุดเวลา)
- **FAUNA:** ผีเสื้อ 14 ตัวบินวนเป็นวงหลวม **รอบตัวคนที่กำลังเดิน** (ระดับพุ่มไม้,
  เฉพาะกลางวัน กลางคืนหยุดพัก/ซ่อน) และนก 7 ตัวบินเป็นวงรัศมี 16–42 m สูง 12–23 m
  กระพือปีก — ทั้งคู่เป็น InstancedMesh ปรับทุกเฟรม, ตำแหน่ง deterministic จาก seed
- โหมด VR/AR: ไม่ move camera — move ทั้งโลก (world group) แทน
  เท้าจึงอยู่ที่ระดับพื้นเสมอ (local-floor reference space)

### หน้าจอธรรมดา (fallback แบบโจทย์: FPS game)

ถ้าอุปกรณ์ไม่รองรับ WebXR (หรือปิด XR): ใช้ **WASD เดิน + เมาส์ (pointer-lock) / ลากนิ้ว มองรอบตัว**
แบบเกม FPS — ภูมิประเทศ/พืช/ fauna /การชนชุดเดียวกันทั้งหมด
(กด **Space ค้าง** เพื่อทดลอง gaze-walk บนจอธรรมดาได้)

## การจัดโซนพืช (species zones)

`computePines` วางพืชด้วย lattice ช่อง 12 m → แต่ละช่องถูกสุ่มเลือกชนิด (ถ่วงน้ำหนัก
สน .34 / ทรงกลม .18 / พุ่ม .15 / กล้วย .17 / ล้มลุก .16) แล้ว **smooth ด้วย
majority ของเพื่อนข้างเคียง 2 รอบ** → โซนชนิดเดียวกันเป็นก้อนใหญ่; ตรวจชนิด ณ จุดใด
ด้วย `speciesAt(x,z)` ระยะห่างขั้นต่ำต่อชนิด: pine/round 3.0, banana 2.2, shrub 1.8,
herb 1.0 m — seeded → layout เหมือนเดิมทุกครั้ง (ค่าเริ่มต้น 320 ต้น, `?trees=N`)

## การใช้งาน

ต้องมี **HTTPS หรือ localhost** เท่านั้นถึงจะใช้ WebXR ได้:

```bash
cd SCMA292_lesson12/walking_xr
python3 -m http.server 8080
# บนเครื่องตัวเอง: เปิด http://localhost:8080/ (Chrome on Android ก็ใช้ได้ผ่าน localhost)
# บนมือถืออื่นในวง LAN: เปิด http://<IP เครื่อง>:8080/ — ถ้า browser ไม่ยอมให้ใช้ XR บน http://
#   ให้ tunnel HTTPS เช่น `cloudflared tunnel --url http://localhost:8080`
```

- กดปุ่ม **"เข้าโหมด VR"** ใน面板 (browser ต้องการ user gesture สำหรับ requestSession)
- ไม่มี headset / browser ไม่รองรับ → เป็นโหมดจอธรรมดาอัตโนมัติ

## ความปลอดภัย

- เคลียร์พื้นที่เดินจริง ≥ 2×2 m หรือใช้แบบนั่งเก้าอี้
- หยุดทันทีเมื่อเวียนศีรษะ (โหมดจอธรรมดามี WASD ใช้ได้โดยไม่มีพื้นที่)

## โครงสร้างโค้ด

- `index.html` — ไฟล์เดียวจบ:
  - **Section 1 — math ล้วน** (ทดสอบได้โดยไม่ต้องการ browser): `terrainH`,
    `terrainGrad`, `slopeDeg`, `speciesZones`, `computePines` (seeded rejection
    sampling ในโซน), `chooseStart`, walk logic (`bowRamp`, `smoothSpeed`,
    `advance`, `canOccupy`) — port/ขยายจาก `../old_version/walk-terrain.html`
    (ผ่าน harness 79/79) ค่า `engage` = **20° ตามโจทย์**; พารามิเตอร์ภูมิประเทศ
    ทั้งหมดคูณ 3 พร้อมกันเพื่อขยายพื้นที่โดยคงสัดส่วนเดิม
  - **Section 2 — three.js scene:** terrain BufferGeometry + vertexColors,
    forest InstancedMesh 6 meshes (trunk/branch, cone, crown-blob, banana-stem,
    leaf-plane ทั้งแบบใบห้อยและbladeตั้ง, bloom=ผล/ดอกไม้), decor หิน+หญ้า,
    fauna InstancedMesh (นก+ผีเสื้อ) — ไม่มีป้าย/board ในฉาก (invariant ui3d=0)
  - **Section 3 — modes:** probe `immersive-vr` → `immersive-ar` → flat FPS;
    loop เดียวทุกโหมด
- `three.module.js` — three.js r169 vendored (สำเนาจาก `../../vr-terrain/`)
  ใช้ผ่าน importmap ไม่ต้องต่อ internet

### URL/debug hooks (สำหรับทดสอบ headless)

- `?pos=x,z` ตำแหน่งเริ่ม, `?look=pitch,yaw` (องศา, โหมด flat),
  `?walk=1` บังคับ gaze-walk, `?seg=128` ความละเอียด terrain (ลดเป็น 96/64 ได้),
  `?trees=N` จำนวนพืช, `?tod=ชม.` / `?dayspeed=×`
- **ค่าเริ่มต้นของหน้า: ไม่มีข้อความใดเลยบนจอ** — เหลือแค่ปุ่มเข้าโหมด VR/AR
  (ตามคำขอผู้ใช้); `?ui=1` = แสดงแผงคำอธิบาย + สถานะ debug, `?ui=0` = ปิดแม้แต้ปุ่ม
- `window.__app.status() / setPlayer / setLook / setTod / probe(x,z) / enterXR`
  (status รวม `half`, `treeTypes`, `fauna` sample positions)
